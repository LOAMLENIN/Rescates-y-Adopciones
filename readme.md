# Sistema de Control de Rescates y Adopciones

## Actividad Unidad 2: Maquetación HTML5

Este proyecto consiste en el desarrollo de un prototipo estructural web para gestionar información sobre rescates y adopciones de animales, utilizando HTML5 y etiquetas semánticas.

## Objetivo

Implementar la estructura fundamental de un sistema web de Control de Rescates y Adopciones, aplicando principios de accesibilidad, interoperabilidad y estándares W3C.

## Archivos del proyecto

- **index.html:** Página principal del sistema.
- **reportar.html:** Formulario para registrar información de rescates.
- **rescates.html:** Tabla de consulta de rescates y sus estados.

## Tecnologías utilizadas

- HTML5
- Visual Studio Code
- Git y GitHub
- W3C Nu Html Checker

## Validación

Los tres archivos HTML5 fueron comprobados mediante el validador W3C, sin errores ni advertencias.

## Control de versiones

Se utiliza la metodología Gitflow mediante las ramas:

- main
- develop
- feature/maquetacion-html

## Alcance

El proyecto es un prototipo estructural HTML5. Incluye navegación entre páginas, validación nativa de campos del formulario y una tabla de datos de ejemplo. No incluye almacenamiento persistente ni backend.
